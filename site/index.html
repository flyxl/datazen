Frequently asked questions

DataZen at a glance

What is DataZen?

A free, open-source desktop database workspace with AI-assisted querying, analysis, visualization, automation, and MCP integration.

Which databases are supported?

PostgreSQL, MySQL/MariaDB, SQLite, and Redis are included by default, with optional drivers for MongoDB, ClickHouse, DuckDB, SQL Server, and more.

Does data leave my device?

Database credentials stay encrypted locally. AI requests go only to the provider and endpoint you configure.

Can AI agents use it?

Yes. DataZen works as both an MCP server for external agents and an MCP client for bringing external tools into AI Chat.

Is it really free?

Yes. DataZen is GPLv3-licensed, requires no DataZen account, and provides builds for macOS, Windows, and Linux.

What makes it different?

AI receives real database context, while charts and reusable cross-database workflows remain inside the same lightweight desktop app.
