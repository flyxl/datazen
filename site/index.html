MCP Server & Client

Give your AI agents access to your databases

DataZen ships with a built-in MCP server: expose queries, schema inspection, EXPLAIN and even whole workflows as tools for the agents you already use.

  • Works with Claude Desktop, Cursor, Cline and any MCP-compatible client
  • Doubles as an MCP client — connect external MCP servers inside DataZen
  • Headless mode (--mcp-stdio) for servers, scripts and CI
  • Your credentials stay in the OS keychain — agents never see them raw
