📊 图表可视化

查询结果不用导出到 Excel，点一下就从表格变成图。字段类型自动推断、图表智能推荐，数据探索零门槛。

一键切换

表格 ↔ 图表，零配置

执行查询后，在结果上方一键切到图表视图。首次切换自动运行智能推荐：根据字段类型和行数，给出最合适的图表与坐标轴配置。

  • 时间列 + 数值列 → 折线图（时间序列）
  • 分类列 + 数值列 → 柱状图 / 饼图（对比与分布）
  • 多个数值列 → 散点图（相关性）
  • 单个数值列 → 面积图（趋势）
五种图表

覆盖常见分析场景

折线、柱状、饼图、散点、面积五种图表类型，轴、聚合方式与分组维度都可配置，工具栏随时调整。

  • 数值聚合：sum / avg / count / min / max
  • 多维度分组：按第二个分类列分系列
  • Tooltip 展示字段名、数值与百分比（饼图）
  • 5 套预置调色板 + 暗色主题适配
导出与复用

结果带走，汇报无忧

图表可以导出为高清 PNG 或矢量 SVG，直接用于文档、PPT 与报表。图表配置按查询记忆，切回表格再切回来也不丢。

  • PNG（含暗色背景）/ SVG 两种导出格式
  • 图表配置随查询持久化记忆
  • Workflow 步骤结果同样支持图表化
