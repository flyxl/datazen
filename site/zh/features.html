MCP Server & Client

你的数据库，成为 AI Agent 的工具

DataZen 内置 MCP（Model Context Protocol）Server。把 Claude Desktop、Cursor 或任何兼容 MCP 的 Agent 指向它，它们就能检视 Schema、执行查询、读取 EXPLAIN 计划——甚至触发整条 Workflow。

  • MCP Server：把数据库操作、Schema 检视、EXPLAIN 与 Workflow 封装成 MCP 工具
  • MCP Client：在 DataZen 内连接外部 MCP Server 并调用其工具
  • 无头模式：用 --mcp-stdio 运行于服务器、脚本或 CI，无需界面
  • 凭据留在本地：Agent 只与 DataZen 通信，密码始终保存在系统钥匙串
  • 持久化连接：Agent 通过连接 ID 访问已保存的连接，无需接触原始连接串

SQL 编辑器

为日常查询打磨

  • 语法高亮 + 表名 / 列名自动补全
  • 多语句执行、查询历史与收藏
  • SQL 方言按连接类型自动切换
  • 查询结果上限可配，大结果集不卡界面
数据浏览与编辑

十万行也不卡

  • 虚拟滚动大表，10 万行级流畅滚动
  • 行内编辑、安全批量删除、事务支持
  • 排序、筛选、分页组合使用
  • 导出 CSV / JSON / SQL，导入同源格式
备份与同步

数据在手，心里不慌

  • 一键备份为 SQL 文件：Schema-only / Data-only / Gzip
  • 完整应用数据打包导出（含配置），原子写入 + ZIP 炸弹防护
  • Data Sync — 同方言族、结构与主键一致时的行级差异同步
  • Data Transfer — 异构库单向迁移，六步向导（结构 / 数据 / 二者）
  • Schema Diff — 五步向导：结构对比与受控 DDL 部署（默认仅增量变更）
  • 备份包自动排除密钥文件
安全与隐私

默认安全的设计

  • 连接密码加密存储，主密钥在系统钥匙串
  • SSH 凭据加密，首次连接校验主机指纹
  • 本地通信加固，文件访问仅限可信路径
  • SQL / 自然语言请求默认不落 info 日志
