MCP 实战：让 AI Agent 连接你的数据库

从"和数据对话"到"让 Agent 帮你跑查询"——一行配置即可。

2026 年 9 月 · 约 8 分钟阅读

什么是 MCP？

Model Context Protocol（MCP）是一种向 AI Agent 暴露工具、资源和提示的标准协议。可以把它理解为 AI 的 USB-C 接口——你只需实现一个协议，任何兼容的客户端都能连接。

DataZen 同时内置了 MCP Server（将数据库暴露给外部 Agent）和 MCP Client（将外部工具接入 DataZen 的 AI 聊天）。本文通过实际案例覆盖两个方向。

MCP Server：将数据库暴露给 Agent

有哪些工具可用？

DataZen 作为 MCP Server 运行时，会向连接的 Agent 暴露以下工具：

工具 描述
list_connections 列出所有已配置的数据库连接
list_tables 列出连接中的表和视图
describe_table 获取列定义、索引和约束
execute_query 运行 SELECT 查询并返回结果
explain_query 获取查询的 EXPLAIN 计划
run_workflow 按名称或内容执行 YAML Workflow

凭据不会离开 DataZen。Agent 通过 Server 与数据库交互——它永远看不到原始密码。

在 Claude Desktop 中配置

在 Claude Desktop 的 MCP 配置中添加：

{
  "mcpServers": {
    "datazen": {
      "command": "/path/to/datazen",
      "args": ["--mcp-stdio"]
    }
  }
}

就这么简单。重启 Claude Desktop，你的 Agent 就能检查 Schema、运行查询，甚至执行跨库 Workflow。

真实案例："找出最慢的查询"

连接 Claude 后，你可以这样问：

"列出 orders 数据库的所有表，描述 orders 表的结构，然后查询最近 7 天的订单。"

Agent 会自动串联 list_tables → describe_table → execute_query，用从 Schema 学到的列类型写出正确的 WHERE 子句。无需手动注入 Schema，无需复制粘贴表结构。

MCP Client：将外部工具接入 DataZen

反向同样强大。DataZen 可以作为 MCP Client，连接外部 MCP Server 并在 AI 聊天侧栏中使用其工具。

例如，你可以连接：

  • 文件系统 MCP Server——让 AI 读取 CSV 文件用于导入
  • GitHub MCP Server——将数据库问题与代码提交关联
  • 自定义内部 API Server——AI 可以同时调用 API 和数据库查询

在 设置 → AI → MCP Client 中配置外部 MCP Server，它们就会出现在聊天侧栏的可用工具列表中。

无头模式：--mcp-stdio

DataZen 不仅仅是桌面应用。--mcp-stdio 标志启动一个无头 MCP Server——没有 GUI，没有 Tauri，只有纯 Rust 通过 stdin/stdout 响应 JSON-RPC 消息。

这打开了服务端使用场景：

  • CI/CD 流水线：让 Agent 在部署前验证 Schema 变更
  • ChatOps：通过 MCP 桥接将 Slack 机器人连接到数据库
  • 脚本化：将 Agent 输出管道到自动化数据库维护任务
# 启动无头模式
datazen --mcp-stdio

# 或从 Docker 容器运行
docker run -i datazen/datazen --mcp-stdio < config.json

安全模型

  • SQL Guard 对所有查询生效——包括来自 MCP Server 的查询
  • 只读连接通过 MCP 访问时仍然是只读的
  • 凭据加密存储在系统钥匙串中，MCP Server 使用连接 ID 而非原始密码
  • 无文件系统访问。无头模式不能读写文件——仅通过 stdio 通信

下一步

  • 流式查询——大数据集结果增量返回
  • Resource URI——将表和 Schema 作为 MCP Resource（只读）暴露
  • 按工具权限控制——精细控制每个 Agent 可访问的工具
