安装说明

macOS 首次打开

应用未经 Apple 公证，首次打开若提示「已损坏」或「无法验证」，请执行：

xattr -cr /Applications/DataZen.app

或右键应用 → 打开 → 在弹出的对话框中点击「打开」。我们正在推进公证，以去掉该步骤。

Windows

运行 NSIS .exe 安装包即可；SmartScreen 提示时选择「仍要运行」。 如需免安装版本，解压 Portable .zip 后直接运行 DataZen.exe。

连接你的数据库

启动后点击「新建连接」，选择数据库类型并填写地址；支持 PostgreSQL、MySQL / MariaDB、SQLite、Redis 以及插件驱动。

常见问题

需要注册吗？

不需要。下载安装即可使用，无需注册任何账号。

我的数据会去哪里？

数据库数据与连接凭据只保存在你的电脑上——DataZen 不运营任何云服务，数据不会经过我们的服务器。只有当你使用 AI 功能时，Schema 与查询上下文才会发送给你自己配置的 AI 服务商（OpenAI / Anthropic / DeepSeek / 自定义端点）。

AI 需要 API Key 吗？

需要，自行配置自己的 Key。普通数据库查询和浏览完全不需要 AI。

可以商用吗？

可以。DataZen 采用 GPLv3 协议，公司内部业务使用没有问题；如果你分发 DataZen 本体或其修改版，则需按 GPLv3 开放对应源码。嵌入产品分发的场景请阅读 GPLv3 条款。

支持哪些数据库？

PostgreSQL、MySQL / MariaDB、SQLite、Redis 内置；其他数据库可通过插件扩展。

支持 Linux？

支持，提供 x86_64 的 .deb、.rpm 与 AppImage。

自动更新？

支持。可在设置中查看更新或开关自动更新。
