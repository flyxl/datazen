# Task 11 Report — RedisJSON probe + editor

**Branch:** `feat/redis-deep-ops-e2-e4`  
**Spec:** §7.2 RedisJSON  
**Commit message:** `feat(redis): RedisJSON tree editor with module probe`

## Summary

Implemented RedisJSON backend commands, module capability probe, and a standalone tree editor component. Wiring into `KeyEditors.tsx` / workbench create-type list is deferred (Task 11 partition).

## Backend

| Command | Args | Returns |
|---------|------|---------|
| `json_get` | `connectionId`, `dbIndex`, `key`, `path?` (default `$`) | `{ value: Json \| null }` |
| `json_set` | `connectionId`, `dbIndex`, `key`, `path`, `value` (JSON string) | `()` |
| `json_del` | `connectionId`, `dbIndex`, `key`, `path` | `{ deleted: number }` |

- **`ops_json.rs`**: `JSON.GET` / `JSON.SET` / `JSON.DEL` helpers, root unwrap for `$` replies, `has_redis_json()` probe.
- **`plugin.rs` / `redis_driver.rs`**: wired via `plugin_on_db!` macros.
- **Permissions**: `allow-json-get`, `allow-json-set`, `allow-json-del` in `default.toml` + autogenerated TOML.

## Frontend

- **`hasRedisJson.ts`**: `hasRedisJson(modules: string[])` — true when list contains `ReJSON` or `RedisJSON` (case-insensitive).
- **`JsonEditor.tsx`**: probes `modules_list` on mount; shows muted message when module absent; tree editor with expand/collapse, scalar edit, add field/element, delete path when module present.
- Exported invoke helpers: `invokeJsonGet`, `invokeJsonSet`, `invokeJsonDel`, `invokeModulesList`.

## i18n

11 new `redis.json*` keys in all 10 locale files (en/zh-CN/zh-TW translated; Beta locales mirror English).
