# V2EX — 开发者社区帖子

**标题：** [开源] DataZen — 基于 Tauri + Rust 的 AI 原生数据库客户端，<15MB

**正文：**

大家好，分享一个我在做的开源项目 DataZen。

DataZen 是一款基于 **Tauri v2 + Rust** 构建的桌面数据库客户端，核心理念是「让 AI 处理数据库工作，让数据真正产生洞察」。

**核心功能：**

1. **AI 原生集成** — 不是简单的 ChatGPT 外挂，而是将 AI 深度集成到数据库工作流中：
   - 自然语言 → SQL（基于当前 Schema 上下文生成）
   - SQL 执行错误诊断
   - EXPLAIN 执行计划分析 + AI 瓶颈识别
   - 带数据库上下文的 AI Chat

2. **轻量级** — 安装包 <15MB，Tauri + Rust 带来快速启动

3. **数据可视化** — 查询结果直接生成图表（折线、柱状、饼图、散点、面积图），无需导出到 Excel

4. **YAML Workflow 自动化** — 用 YAML 编排 SQL、AI、条件和循环，支持跨数据库操作（比如一个 Workflow 同时查 PostgreSQL 和 MySQL）

5. **MCP 集成** — 同时支持 MCP Server 和 Client：
   - Server：向外部 AI Agent 暴露数据库能力
   - Client：将外部工具接入 AI Chat
   - 支持 stdio headless 模式

6. **可扩展 Driver 架构** — 编译时集成，非运行时动态加载。Driver API 已作为 MIT crate 发布到 crates.io

**支持的数据库：**
- 默认：PostgreSQL、MySQL/MariaDB、SQLite、Redis
- 可选：MongoDB、ClickHouse、DuckDB、SQL Server

**安全：**
- AES-256-GCM 加密
- 本地优先，无云服务
- SSH 隧道支持

**技术栈：** Tauri v2、Rust、React 18、TypeScript、Tailwind CSS 4、Zustand、CodeMirror 6

目前是 v0.1.0 早期阶段，欢迎试用和反馈！
