## Bug 场景

在查询结果图表视图中，用户通过左侧轴配置面板将「分组」字段设置为与 X 轴相同的分类字段（如 `status`）后，或在表格↔图表视图来回切换且配置中保留了该分组设置时，图表区域仅显示坐标轴和网格线，但数据条/柱/扇形等图形元素完全不渲染。此状态下无法点击数据点触发图表↔表格联动。

## 重现步骤

1. 启动 DataZen 应用（`pnpm tauri dev`）
2. 双击 PostgreSQL 连接 `goecoride` 打开数据库窗口
3. 新建查询，执行：
   ```sql
   SELECT status, COUNT(*) as count FROM product GROUP BY status ORDER BY count DESC LIMIT 20
   ```
4. 点击结果区域的「图表」按钮切换到图表视图
5. 确认初始状态下柱状图正常渲染（蓝色柱体可见，高度约 136）
6. 在左侧「图表配置」面板中，将「分组」下拉框从「无」改为 `status`
7. 观察图表区域

**可选附加步骤（验证持久化场景）：**

8. 点击「表格」切换回表格视图
9. 再次点击「图表」切换回图表视图
10. 观察图表区域

## 预期结果

1. 更改分组字段后，图表应实时更新并正确渲染数据
2. 表格↔图表切换后，图表应正常显示且配置保持不变
3. 图表上的数据点/柱体可点击，触发联动跳转

## 实际结果

1. 步骤 7 后：图表区域仅显示 Y 轴刻度（0–140）、X 轴标签（`published`）和网格线，**无任何柱体/数据图形**
2. 步骤 10 后：同样只显示坐标轴和网格，柱体仍不渲染
3. 配置面板显示 X 轴=`status (categorical)`、Y 轴=`count`、分组=`status`，配置已持久化但图表不可用
4. 无法点击数据点测试图表↔表格联动

## 截图

测试过程中观察到：
- 初始状态（分组=无）：柱状图正常渲染，蓝色柱体高度约 136
- 设置分组=status 后：坐标轴和网格可见，柱体消失
- 表格↔图表切换后：问题持续，重新执行查询也不能恢复渲染
