## Bug 描述

### 场景
在主窗口中右键点击一个连接，选择"删除连接"菜单项时，连接被立即删除，没有弹出确认对话框。

### 预期结果
点击"删除连接"后，应弹出确认对话框（例如："确定要删除连接 'xxx' 吗？此操作不可撤消。"），用户确认后再执行删除。

### 实际结果
点击"删除连接"后，连接被立即从列表中移除，没有任何确认提示。用户无法撤销误操作。

---

## 重现步骤

1. 启动 DataZen 应用
2. 在主窗口的连接列表中，右键点击任意连接
3. 在弹出的上下文菜单中选择"删除连接"
4. **实际结果**：连接立即被删除，没有确认对话框
5. **预期结果**：弹出确认对话框，用户确认后才执行删除

---

## 根因分析

**文件**：`src/windows/main/MainWindow.tsx` 第 283 行

```typescript
items.push(await MenuItem.new({
  text: t('main.ctx.deleteConnection'),
  action: () => { void deleteConnection(conn.id); }
}));
```

菜单项的 `action` 回调直接调用 `deleteConnection(conn.id)`，没有先弹出确认对话框。

**Store 层**：`src/stores/connectionStore.ts` 第 141-151 行

```typescript
deleteConnection: async (id) => {
  set({ loading: true, error: null });
  try {
    await connectionCommands.deleteConnection(id);
    await get().fetchConnections();
    await get().fetchGroups();
    void emitCrossWindow(EVENT_CONNECTIONS_CHANGED);
  } catch (e) {
    // ...
  }
},
```

Store 层也没有任何确认逻辑。

---

## 修复建议

在 `MainWindow.tsx` 的删除菜单项 action 中添加确认对话框：

```typescript
items.push(await MenuItem.new({
  text: t('main.ctx.deleteConnection'),
  action: async () => {
    const confirmed = await ask(
      t('main.confirmDeleteConnection', { name: conn.name }),
      { title: t('main.deleteConnection'), kind: 'warning' }
    );
    if (confirmed) {
      void deleteConnection(conn.id);
    }
  }
}));
```

## 影响范围

- **影响**：所有用户在主窗口中删除连接时都会受到影响
- **风险**：误删除连接后需要重新配置，特别是含有复杂 SSH 隧道或 SSL 配置的连接
- **关联测试用例**：TC-CONN-009

---

## 修复说明

**修复方案**：在 `MainWindow.tsx` 的删除菜单项 action 中，使用 Tauri dialog plugin 的 `ask` 函数弹出确认对话框，用户确认后才执行删除操作。

**修改文件**：
- `src/windows/main/MainWindow.tsx` — 删除菜单项增加确认对话框
- `src/locales/zh-CN.ts` — 新增确认消息 key
- `src/locales/en.ts` — 新增确认消息 key
