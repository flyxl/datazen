# DataZen 黑盒测试用例集

> 测试用例编号规则：`TC-{模块}-{序号}`
> 优先级：P0（阻塞级）、P1（重要）、P2（一般）、P3（低优先级）

---

## 模块一：连接管理 (CONN)

### TC-CONN-001 — 新建 PostgreSQL 连接（正向）

| 项目 | 内容 |
|------|------|
| **优先级** | P0 |
| **前置条件** | 应用已启动，PostgreSQL 实例运行中 |
| **测试步骤** | 1. 点击主窗口「新建连接」按钮或按 `Cmd+N`<br>2. 在连接类型中选择 PostgreSQL<br>3. 填写 Host: `localhost`, Port: `5432`, User: `postgres`, Password: `password`, Database: `testdb`<br>4. 点击「测试连接」<br>5. 测试通过后点击「保存」 |
| **预期结果** | 1. 新建连接窗口正常打开<br>2. 表单字段正确显示 PostgreSQL 默认值<br>3. 测试连接成功，显示服务器版本<br>4. 保存后返回主窗口，连接列表中出现新连接 |
| **测试数据** | Host: localhost, Port: 5432, User: postgres, Password: password, DB: testdb |
