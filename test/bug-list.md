# DataZen Bug 清单

> 每个 Bug 单独记录在 `test/bugs/BUG-XXX.md` 文件中
> 严重等级：S1（崩溃/数据丢失）、S2（功能不可用）、S3（功能异常但有替代方案）、S4（UI/体验问题）

## Bug 状态约定

| 状态 | 含义 | 说明 |
|------|------|------|
| **待修复** | Bug 已确认，等待开发修复 | 初始状态 |
| **待验证** | 开发已修复代码，等待测试回归验证 | 修复后不能直接改为"已验证"，必须先经过测试人员回归确认 |
| **已验证** | 测试人员回归验证通过 | 最终状态，需记录验证方法和验证人 |
| **已关闭** | 非 Bug 或无需修复 | 需说明关闭原因 |

> **重要**：修复 Bug 后，状态只能改为「待验证」，不能直接改为「已验证」。
> 必须由测试人员通过黑盒测试回归确认后，才能改为「已验证」。
