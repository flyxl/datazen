## 优先级总结

### 高优先级（核心体验提升）
- 数据库/Schema 节点添加「查看关系图」入口

### 中优先级（功能完善）
- 连接节点添加「复制名称」「新建查询」「刷新」
- 数据库节点添加「历史查询」「执行 SQL 文件」「新建 Schema」「在数据库中查找」
- Schema 节点添加右键菜单（当前完全没有）
- 分类节点添加右键菜单（新建表、导入数据、刷新）
- 数据传输/比较架构/比较数据 入口（后端 DataSync 模块已有能力）

### 低优先级（Nice to have）
- 置顶功能
- 可见对象过滤器 / Schema 过滤器
- 查看资源对象 / 浏览对象
- 用户与权限 / 进程列表 / 服务器仪表盘
- 数据库备份
- 文档功能
- 编辑数据库属性 / 编辑注释
- 更多 → 子菜单
