## 优先级总结

### 已实现 ✅
- 连接节点：复制名称、新建查询、刷新
- 数据库节点：查看关系图、在数据库中查找、数据传输、比较架构、比较数据
- Schema 节点：完整右键菜单（复制名称、新建查询、刷新、查看关系图、在数据库中查找、新建表、导入数据、数据传输、比较架构、比较数据）
- 分类节点：新建表、导入数据、刷新
- 函数/存储过程/触发器：复制名称
- 表/视图节点通过 `nodeContextMenuRef` 委托完整菜单

### 需要新基础设施（暂不实现）
- 历史查询 → 需要新增查询历史功能模块
- 执行 SQL 文件 → 需要新增文件选择器 + SQL 批量执行流
- 新建数据库 → 需要 CREATE DATABASE 命令支持
- 新建 Schema → 需要 CREATE SCHEMA 命令支持
- 删除 Schema → 需要 DROP SCHEMA 命令支持
- 导出全部数据库 → 需要新增跨数据库批量导出

### 低优先级（Nice to have）
- 置顶功能
- 可见对象过滤器 / Schema 过滤器
- 查看资源对象 / 浏览对象
- 用户与权限 / 进程列表 / 服务器仪表盘
- 数据库备份
- 文档功能
- 编辑数据库属性 / 编辑注释
- 更多 → 子菜单
- 设为默认 Schema
- 关闭数据库连接
- 取消默认数据库
