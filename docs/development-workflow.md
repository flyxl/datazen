1. 在新分支里面开发

2. 创建进度管理文件，每开发完成一个功能就更新这个文件。功能开发的时候需要写单元测试用例进行测试

3. 完成一个功能之后，创建新的agent测试该功能，禁止使用原来的agent进行测试。这步需要输出E2E测试用例和测试结果，如果有bug的话需要记录bug重现步骤。这一步只输出测试结果，不需要修复问题

4. 测试agent完成测试任务之后，如果测试不通过，需要调用编码agent修复测试发现的问题

5. 在完成一个功能开发并且测试通过之后提交代码。按照上述循环，完成所有功能

6. 所有功能完成之后，更新相关的系统文档，至少包括系统架构文档，[AGENT.md](http://AGENT.md)文档等，然后合并代码到main分支并commit+push代码
