# DataZen 全量迁移到 Rune

目标：桌面和 Web 的产品界面最终都来自 `crates/datazen-ui`。Core、Driver、Server、权限和扩展沙箱不重写。React 在每一块迁移完成前继续负责那一块，不能中途删掉。

已完成，不再重做：

- Rune crate 骨架能编译。
- SQL Editor：文档和多选区在状态里，输入法不进文档，长行横滚。
- DataGrid：`virtual_rows`、列窗口、冻结首列、单元格编辑、TSV 复制粘贴。

## 不变量

1. UI 只依赖 `datazen-ui-api`。不依赖 Tauri、Axum、React 或某个 Driver。
2. 桌面 Host 和 Web Host 调用同一套 application use case。禁止在 Rune Host 里再写一套连接、Runtime 或驱动注册。
3. 异步结果要带请求代次。断开连接或关掉面板后，过期响应不能写进新状态。Rune 的 `Latest<T>` 只解决“只要最新一份”，不代替这个屏障。
4. 选择、脏数据和编辑器状态放在模型里，不放在会被虚拟化拆掉的行节点上。
5. Web 没有第二窗口、系统菜单、文件对话框和 WebGL 退路。这些交互改成同一窗口里的面板，或暂时留在旧页面。
6. WAPP 的 iframe 沙箱不进 Canvas。React 插件和 Pro 界面在中立贡献协议出现之前不嵌进 Rune。
7. 主 SQL Editor 和主 DataTable 在对应阶段的验收没过之前，不被 Rune 版本替换。

## 阶段

### 1. 端口和第一条数据路径

建立 `crates/datazen-ui-api`：连接、会话、表页、单元格暂存。UI 通过这个接口读数据。先用内存实现把界面跑起来，桌面和 HTTP 适配器以后换进去，界面代码不动。

退出标准：连接列表来自端口；打开表后网格显示这一页的真实格子，而不是 `r0c0` 这种占位；改一格能回到端口。

### 2. 工作区壳

用现有产品的信息架构换掉占位页：

- 连接首页
- 左侧对象树
- 标签页：表数据、查询、结构
- 查询页上半是 SQL Editor，下半是结果网格
- 设置页只列已经有端口的项

退出标准：不连数据库也能在壳里走完“选连接 → 打开表 → 看格子 → 打开查询标签”。对象树先用端口给出的表名。

### 3. 表数据垂直切片

把 `TableDataApi` 接到现有 table browsing / table editing use case。分页、排序、过滤、只读原因、脏写回和失败回滚按 `docs/architecture/frontend/data-table.md` 验收。结果网格和表网格分开准入。

退出标准：对一个真实会话翻页、改格、提交、失败后界面和存储一致。列窗口和冻结列仍然有效。

### 4. 查询垂直切片

SQL Editor 补齐撤销、查找替换、语句选择。执行、取消和结果读取走 `QueryApi`。结果用同一个 DataGrid。补全、诊断、悬浮提示在 Web 没有 overlay 时做成画布内面板。

退出标准：输入、执行、取消、看结果、写回安全判定可用。没过关就不替换现在的 CodeMirror 查询页。

### 5. 对象与结构

Schema 树、DDL、列、索引、外键、ER 图。ER 图沿用现有“宽表默认折叠”。结构编辑器在能预览变更计划之后再替换。

### 6. 设置、导入导出、备份

设置按能力声明渲染，桌面和 Web 缺的能力直接标出来。导入、导出、备份走现有 job。文件对话框在 Web 上走浏览器选择，不假装有原生对话框。

### 7. 对比、同步、传输、仪表盘、工作流

这些现在是独立窗口。Rune 里做成工作区里的向导面板，步骤状态放在端口后面。仪表盘图表先用静态图元验证，不在这一步引入新的绘图栈。

### 8. Host

- `datazen-rune-desktop`：只做窗口、菜单、文件和托盘，业务调用桌面 application。
- Web：WASM 加载、Canvas 挂载、HTTP/SSE。没有 WebGPU 时继续打开旧 React。
- 中文字体随包提供，不扫描系统字体目录。

退出标准：同一份 `datazen-ui` 在桌面进程和浏览器里打开第 3 阶段的表，结果一致。

### 9. 扩展

Driver 自带界面和 Pro 界面改成中立贡献，不接收 React 组件。WAPP 继续用独立 WebView。做不到这一阶段，React 主界面不能下线。

### 10. 切换

对同一数据集比较滚动、输入和内存。补屏幕阅读器和键盘路径。旧界面只留 WebGPU 退路和尚未迁移的扩展。然后才允许删掉对应的 React 页面。
