# React → Rune 逐文件迁移台账

一个 task 一行，**改状态只改该行方括号里的一个字符**：

- `- [ ]` 待办 · `- [~]` 进行中 · `- [x]` 完成 · `- [!]` 阻塞

状态不落到任何汇总数字里（那会逼着改状态时连带改别的行）：进度用
`node scripts/rune-parity.mjs --progress` 现算。行尾的 area、工作量、涉及文件由脚本生成，
不要手改；React 源码变动后跑 `node scripts/rune-parity.mjs --tasklist` 刷新，
已存在的 T 编号保留原状态。
