MockDriver 记录 `cancel_query` 调用次数，修复后保持为 0；显式 supported 路径保持调用。 | `src-tauri/src/commands/query.rs` 现显式区分 `Some(true)`、`Some(false)` 和 `None`；unknown 返回 `UNSUPPORTED_OPERATION:cancel_query:query cancellation capability is unknown`，不会取得 session 或调用 driver。新增 Host Rust 单测验证 legacy MockDriver 未调用；同测保留 supported/unsupported 行为。`CARGO_TARGET_DIR=/private/tmp/datazen-repair-v01x-query-cancel cargo test -p datazen --lib`：1183 passed / 0 failed / 2 ignored。第二轮独立回归：`cargo test -p datazen --lib commands::query::tests::cancel_query` 3 passed / 0 failed；其中 unknown 拒绝且 MockDriver 调用次数为 0。 |
