# BUG-005 T07 方言/无语言标记的 SQL 代码块显示 Run 但不会执行

- 关联任务：T07 Chat 动作、模式与 egress UI
- 首次被测提交：`ddfd7eccf4ca7ce512c3beee4672418243e9b7ef`
- 修复提交：`89da5431539c6ee1c4ae82d91ba976603291f6b5`
- 严重度：阻塞 T07 验收（“Run 能把代码送到编辑器并执行”对 SQL 方言代码块不成立）
- 状态：已验证（`89da54315`）

## 现象

T07 要求 Chat 代码块里的 SQL 可以点 Run 送到当前查询面板并经过执行 gate。`AiCodeBlock` 用 `isSqlCodeBlock(language, code)` 判断是否显示 Run，识别 `sql`、`mysql`、`postgresql`、`postgres`、`sqlite`、`mariadb`，也识别任意语言标记但首行像 SQL 的代码；但点击 Run 后把原始 language 原样交给 `onRunCode`：

```tsx
// packages/frontend/src/components/ai/AiCodeBlock.tsx:54-56
const handleRun = useCallback(() => {
  onRunCode?.(code, language || 'sql');
}, [code, language, onRunCode]);
```

`ContentView.handleRunCodeFromChat` 只接受精确的 `'sql'`：

```tsx
// packages/frontend/src/windows/connection/ContentView.tsx:300-303
const handleRunCodeFromChat = useCallback(
  (code: string, language: string) => {
    if (language !== 'sql') return;
```

因此以下情况 Run 按钮可见但点击无任何效果：` ```postgresql `、` ```mysql `、` ```sqlite `、` ```mariadb `、` ```SQL `（经 `AiMessageContent` 会小写，但方言不会变成 `sql`），以及无语言/`text` 标记但首行是 `SELECT` 等 SQL 的代码块。当前查询面板的 SQL 不会被更新，也不会触发 `requestQueryRun`/执行；New Query 不经过该语言判断，因此不受影响。

## 复现

1. 让 AI 回复一个 ` ```postgresql ` 代码块，内容为 `SELECT 42`；确认代码块显示 Run 按钮。
2. 打开一个 Query 面板，点击该 Run 按钮。
3. 观察：编辑器 SQL 不变，执行 gate 不触发；换成 ` ```sql ` 同样的代码再点，才会更新/执行。
4. 无语言标记但内容以 `SELECT` 开头的代码块同样显示 Run，但点击无效果。

本次复测把 `ContentView.test.tsx` 的 chat mock 临时改成 `onRunCode('SELECT 42', 'postgresql')`，原“runs chat SQL in the active query panel”用例失败：

```
AssertionError: expected undefined to be 'SELECT 42'
 ❯ packages/frontend/src/windows/connection/__tests__/ContentView.test.tsx:520
```

## 期望

- 只要 `isSqlCodeBlock(language, code)` 为真（或 UI 显示 Run），Run 都应把代码送到当前 Query 面板并走执行 gate；无 Query 面板时创建并只执行一次。
- 真正的非 SQL 代码块不显示 Run，或明确 no-op，不应出现“按钮可见但无反馈”。
- 方言/大小写/无语言标记应有测试，不能只测 `language="sql"`。

## 实际（ddfd7eccf，修复前）

- `AiCodeBlock` 对 `postgresql`/`mysql`/`sqlite`/`mariadb`/`postgres` 和 SQL-looking 无语言代码显示 Run。
- `ContentView` 仅在 language 精确等于 `'sql'` 时执行；其他 SQL 识别结果直接 `return`。
- 现有 `AiCodeBlock.test.tsx` 的 Run 用例只传 `language="sql"`；`ContentView.test.tsx` 的 mock 也只传 `'sql'`，所以全绿没有覆盖这条真实路径。
