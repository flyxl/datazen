## 现象

T01 校准后的 `docs/architecture/frontend/ai.md` 仍有 3 处与 `packages/frontend` 当前代码不符：

1. 1.5 节 EXPLAIN 行把 aiStore 状态键写成 `isAnalyzing`，实际键为 `isAnalyzingExplain`；`isAnalyzing` 只是 `ExplainPanel.tsx` 里从 store 取值后的局部变量名。
2. 1.5 节 筛选行把 aiStore 状态键写成 `isParsing`，实际键为 `isParsingFilter`。
3. 1.7 节仍把 `nlConfig.ts` 列为 ChartToolbar 的自然语言图表配置实现；该文件已在 `f530b575f`（2026-09-12）删除，当前 `ChartToolbar.tsx` 也没有自然语言输入 UI。

```bash
cd .worktrees/datazen-ai-assistant-parity
rg -n 'isAnalyzing|isParsing\b|nlConfig' docs/architecture/frontend/ai.md
```
