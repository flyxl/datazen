# BUG-019 T21 HTTP token 输入框使用未定义的 Tailwind 颜色类 `bg-bg`，前端颜色门禁失败

- 关联任务：T21 MCP Streamable HTTP
- 被测提交：`3b83395f3`（`feat: add opt-in MCP Streamable HTTP transport`），父 `854834623`
- 复测时间：2026-11-06
- 严重度：阻塞 T21。功能路径通过，但新增设置 UI 触发项目既有 Tailwind 颜色门禁，全量前端无法全绿。
- 状态：待修复

## 结论

T21 的 opt-in HTTP transport、Bearer 认证、token 轮换/持久化、loopback bind、端口 0
实际端口、disable/Stop、DELETE/并发隔离以及 stdio 下 T19/T20 回归均通过；但
`McpSettingsSection.tsx` 的一次性 token 输入框使用了未定义的 `bg-bg`，Tailwind 颜色
门禁失败。这是 T21 引入的 UI/主题问题，不是既有环境失败。

## 复现

`packages/frontend/src/windows/settings/McpSettingsSection.tsx:469`：

```text
className="min-w-0 flex-1 rounded-md border border-edge bg-bg px-3 py-2 font-mono text-xs text-fg"
```

`bg-bg` 不在 `packages/desktop/tailwind.config.ts` 的颜色 token 中；可用主题色为
`surface`/`surface-alt`/`surface-raised`/`surface-inset` 等。

```bash
./node_modules/.bin/vitest run scripts/__tests__/tailwind-colour-classes.test.ts
```

实际结果：

```text
AssertionError: expected [ Array(1) ] to deeply equal []
+ [
+   "packages/frontend/src/windows/settings/McpSettingsSection.tsx:469 `bg-bg`",
+ ]
```

期望 `[]`，实际 1 条 dead colour class；7 项中 1 failed / 6 passed。

## 影响

- token 输入框背景没有解析到主题 token，浅色/深色主题下可读性不一致。
- `tailwind-colour-classes` 门禁失败，T21 不能通过前端全量验收。
- 只需把该背景改为已存在的 surface token（或以设计意图选择透明/其他 token）；
  本次仅记录测试失败，未修改生产代码。
