# BUG-007 T09 删除连接 AI 清理一致性

- 关联任务：T09 AppDb v7 AI 笔记/记忆/FTS/审计
- 初始被测提交：`34a5b398223e29ecd984eaef47cefa8bd76d2349`
- 修复提交：`ed3cfb0da3c66313c0f477b04407dabdf56759c7`
- 严重度：已关闭（原阻塞 T09 失败路径）
- 状态：已验证（`ed3cfb0da`）

## 初始缺陷

`DesktopRepository::delete_connection` 先删除并持久化 `connections.json`，随后调用 `purge_connection_ai_data`。清理失败时只 `tracing::warn!`，仍把 JSON 持久化结果原样返回为成功；连接已经从用户目录消失，AI 笔记/记忆/审计却留在 AppDb，永久孤儿且无重试。

本次用临时触发器测试注入清理失败（已还原）：`delete_connection` 返回 `Ok(())`，connection 已消失，但 note/memory 仍在。T09 文档要求“删除连接时同事务清理 notes + memories”，原实现只覆盖成功路径。

## 修复验证（`ed3cfb0da`）

### 范围

5 文件全部 T09：`ai_memory.rs`、`ai_memory_tests.rs`、`connections.rs`、`connections_tests.rs`、`implementation.md`。implementation.md 仅新增 1 行策略说明，明确 purge-first、跨 JSON/SQLite 无事务、persist 失败时连接保留而 AI 已清理的取舍；与代码一致，可接受。无 generated/无关文件。

### 策略与失败路径

新顺序：计算 `next_snapshot`（不改 cache）→ `purge_connection_ai_data`（notes/memories/audit 单个 SQLite `Immediate` 事务）→ `persist_connections_locked(next_snapshot)` → 更新 cache。

- **purge 失败**：`purge_connection_ai_data` 的 `Err` 映射为 `DesktopRepositoryError::WriteError("AI cleanup failed ...")` 并直接 `?` 返回；cache、`connections.json`、notes/memories/audit 都不变，连接仍可查看/使用。
- **persist 失败**：purge 已成功，连接仍在（cache 未更新，旧 JSON 由 atomic write 保留），但 AI 数据已删；代码注释和 implementation.md 都明确这是跨存储无事务的取舍。无永久孤儿。
- **成功**：persist 成功后才把 cache 替换为 `next_snapshot`；连接、notes/memories/audit/FTS 全清。

**判定**：purge 失败路径满足 BUG-007 的一致性要求；persist 失败路径**可接受为非阻塞取舍**——优先避免永久孤儿，代价是删除失败时 AI 数据已丢，连接保留。若未来要求“删除失败也不丢 AI 数据”，需要 outbox/可恢复补偿或改变 catalog 存储；这不是当前 T09 验收的硬性要求，文档已明确。

### 测试

- `delete_connection_cleanup_failure_is_recoverable_and_keeps_ai_data`：触发器 ABORT 让 purge 失败；断言 `delete_connection` 返回 Err、cache 中连接仍在、`connections.json` 仍含连接、note/memory/FTS/audit 都在。移除触发器后重试删除成功，连接/note/memory/FTS/audit 全清。
- 新增 `existing_memory_cannot_be_rehomed_to_another_owner_or_org`：同一 id 跨 owner/org upsert 返回 `AppDbError::Validation`，原 owner/org 内容不变；同 owner 更新仍由既有 `memory_crud_is_scoped_to_organization_and_owner` 覆盖并通过。
- 本次另用临时测试验证 persist 失败取舍（已还原）：purge 成功后把 data dir 设为只读使 atomic persist 失败，`delete_connection` 返回 Err、cache 连接仍在、note/memory 已删除；确认无孤儿但存在已注释的数据丢失取舍。
