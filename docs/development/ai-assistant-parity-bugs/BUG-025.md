# BUG-025 T24 AiWriteProposalHost 测试 rowCount mock 类型导致 tsc 失败

- 关联任务：T24 写入提案与精确确认
- 被测提交：`b9272596c`（`fix: require write SQL and surface proposal row counts`）
- 复测时间：2026-11-07
- 严重度：阻塞 T24 的 TypeScript 门禁。
- 状态：待修复

## 结论

`AiWriteProposalHost.test.tsx` 新增的 unknown rowCount 用例调用
`applyMock.mockResolvedValueOnce({ ..., rowCount: null, ... })`，但默认 mock
的返回类型被推断为 `rowCount: number`，因此 `rowCount: null` 不兼容。

## 证据

```text
$ node scripts/typecheck.mjs --engine=tsc
[typecheck] tsc 7.0.2 — root
packages/frontend/src/components/__tests__/AiWriteProposalHost.test.tsx(130,7):
error TS2322: Type 'null' is not assignable to type 'number'.
[typecheck] FAILED in tsc (root)
```

`vitest` 运行时通过（UI 6 passed），但权威 tsc 失败；违反 T24 的 typecheck
验收。

## 修复建议

将 mock 返回类型显式声明为 `AiWriteApplyReceipt`（`rowCount: number | null`），
或给 `vi.fn` 声明返回类型，使默认和 once 值都允许 `null`。

## 范围

仅测试文件的类型声明；不涉及生产 UI 行为。
