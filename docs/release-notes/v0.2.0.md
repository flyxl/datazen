## 一、版本背景与定位

DataZen 是一款基于 **Tauri v2 + Rust + React** 构建的轻量、跨平台现代数据库桌面客户端。

在数据库工具的选择上，许多开发者常常在两类工具之间做权衡：
- 一类是 **DataGrip** 这样的重量级 IDE：功能极其全面、代码分析极深，但依赖庞大的运行时，内存开销大且启动较慢，在日常轻量排查或小规格机器上运行显得较重；
- 另一类是 **Navicat** 等传统客户端：简单直观，但属于商业闭源软件，且在执行风控、现代代码补全和私有化 AI 协作等细节上相对保守。

**DataZen 的核心目标是做减法与专注**：借助 Rust 和 Web 前端技术，将内存占用稳定在百兆左右，实现随开随用、秒级启动；同时针对日常写 SQL、结构同步、数据排查的高频痛点，提供更贴近现代开发者习惯的执行策略、手滑防御与本地私有 AI 辅助体验。

经过 360+ 次提交迭代，**v0.2.0** 正式发布。以下是本次版本中新增的重点特性与使用说明。

| **适用核心场景** | 大型项目、复杂 PL/SQL 调试、深度性能分析 | 综合企业级数据库维护、传统建模 | **日常开发排查、轻量分析、随开随用的开源快速工具** |

## 三、用户可直观感受到的新功能（附图）

### 1. SQL 编辑器交互与执行模式升级

- **🎯 4 模式精准执行策略**：
  - **Run Current（当前语句，默认）**：基于 AST 与词法扫描，自动识别光标所在的单条 SQL 并只执行该句。无需每次手动用鼠标从头拖选，也不会误跑整个页面的批处理。
  - **Run Selection（选中区域）**：仅执行鼠标高亮划选的 SQL 代码块。
  - **Run All（全量脚本）**：用于执行完整的连续批处理或多段 DDL。
  - **Ask（每次询问）**：在执行前弹出策略确认窗，适合在关键长脚本中审慎执行。
- **📊 明确的 DML 影响行数反馈**：
  - 针对 `UPDATE / DELETE / INSERT` 等修改类语句，提供专用的状态卡片，清晰展示 **受影响行数（affectedRows）** 与精确执行耗时，不再出现令用户困惑的“无数据显示”提示。
- **⚡ Paste as IN 批量剪贴板导入 (`Mod+Shift+V`)**：
  - 从表格或日志中复制了一列 ID（如 `1001\n1002\n1003`），在 `IN ()` 内按下 `Cmd+Shift+V`（Windows: `Ctrl+Shift+V`），即可自动格式化为 `'1001', '1002', '1003'`。
- **✨ 代码片段 (Snippets) 与多光标支持**：
  - 内置常用的 SQL 片段库，工具栏一键插入建表与查询模板；支持多光标同步点选编辑和一键 SQL 格式化美化。

### 2. 生产高危拦截与参数安全门禁

- **🛑 无 WHERE 条件危险更新拦截**：
  - 自动识别没有带 `WHERE` 条件的 `UPDATE` 或 `DELETE` 语句，以及 `DROP TABLE` 这类破坏性 DDL。
  - 执行时自动弹出醒目的红色警告弹窗，展示待执行语句，要求二次确认方可执行。
- **🛡️ 占位符防隐式传 NULL**：
  - 当 SQL 中包含 `:param` 或 `?` 占位符时，如果用户未填值，系统将直接拦截，杜绝将其隐式转为 `NULL` 造成意料之外的全表更新。

---

### 3. Schema Diff 结构比对：基于 DAG 拓扑排序

- **🌲 智能依赖顺序生成**：
  - 重构了 DDL 比对生成引擎，依据外键依赖、主从关系与复合索引构建有向无环图（DAG），严格按照 `主表创建 → 从表创建 → 外键关联 → 复合索引` 的顺序生成 DDL，有效避免外键引用目标未生成而导致的部署报错。
- **⚠️ 迁移风险前置提示**：
  - 自动标出潜在风险项，例如字段类型由长变短（如 `VARCHAR(255)` 改为 `VARCHAR(50)` 可能产生的数据截断）、旧表添加非空约束且未指定默认值等。

![结构比对与依赖同步](https://raw.githubusercontent.com/flyxl/datazen/main/site/assets/screenshots/27-schema-diff-en.png)

### 4. 多模型 AI 支持与本地私有化适配

- **🎛️ 多模型档案自由切换 (Model Profiles)**：
  - 同时支持配置 OpenAI、Anthropic、DeepSeek、本地 **Ollama** 及任何兼容协议的内网自建端点。
- **🔒 模型级独立安全门控**：
  - 针对**本地私有大模型（如 Ollama）**，支持放宽数据出境限制，允许携带表结构字段与数据样本，以便大模型能充分理解业务关系，提升 SQL 生成与排错的准确度；
  - 针对**公网商业模型**，自动执行敏感凭据擦除与脱敏过滤。
- **💡 SQL 错误一键带入 AI 诊断**：
  - 查询发生错误时，结果面板旁提供快速入口，一键将数据库原生报错信息和当前 SQL 注入 AI 窗口进行诊断。

### 5. 查询结果快速转图表 & 原生 Redis 支持

- **📊 结果集一键切图表**：
  - 查询出的结果集，可在右上角直接一键切换为折线图、柱状图、饼图、散点图，方便快速查看趋势分布，支持导出 PNG 或 SVG。
- **🗄️ 内置原生 Redis 驱动**：
  - 除主流关系型数据库外，内置了原生 Redis 驱动，支持 Key 树层次浏览、命令行交互、实时 Monitor 监控以及 Pub/Sub 订阅发布测试。

### 6. 底层性能与平滑体验

- **⚡ 万级字段毫秒级秒开**：
  - 引入驱动层 `get_all_columns` 批量预拉取与缓存，在左侧导航树中展开包含上百张表的数据库时流畅秒开。
- **🔐 敏感凭据自动脱敏**：
  - 复制连接配置或导出错误日志时，密码、Token 及本地文件绝对路径自动由正则进行星号模糊化。
