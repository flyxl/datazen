### Driver Commands（Observe / Read）

- **`list_processes`** / **`kill_process`**：PG `pg_stat_activity`；MySQL `information_schema.PROCESSLIST`
- **`server_status_snapshot`**：uptime、version、connections、active queries、database size（只读）
- **`estimate_table_rows`**：`information_schema` / `pg_class.reltuples` 廉价估计

### Host

- 连接上下文菜单：`server_status_snapshot` → Server Status；`list_processes` → Process List；`supportsBackup` → Backup/Restore
- **`ProcessListView.tsx`**：DataTable + Refresh/Kill（`execute_driver_command`）
- **`ObjectFilterDialog`**：持久化 `connection.options.objectFilter`，导航树 flatRows 过滤
- 置顶：`ConnectionConfig.pinned`，组内 pinned 优先排序
- **`ServerStatusView.tsx`**：`execute_driver_command` → key-value 表
- **`TableStructureEditor`**：rewrite/destructive 或大行数估计 → `useConfirmDialog` 警告（无 command 时仍按 plan risk 警告）
