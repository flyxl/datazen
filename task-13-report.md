## Plugin commands

| Command | Args | Returns |
|---------|------|---------|
| `dump_keys` | `connectionId`, `dbIndex`, `keys: string[]` | `{ entries: { key, ttlSeconds, dumpBase64 }[], errors }` |
| `restore_keys` | `connectionId`, `dbIndex`, `entries`, `replace: bool` | `{ restored, errors }` |

## Manifest v1

```json
{
  "schemaVersion": 1,
  "dbIndex": 0,
  "keys": [{ "key": "a", "ttlSeconds": -1, "dumpFile": "a.bin" }]
}
```

Zip layout: `manifest.json` + one `.bin` file per key (raw DUMP bytes).

## UI behavior

- **Export:** selected keys or SCAN pattern → `dump_keys` → zip (native save dialog) or JSON (human-readable, lossy metadata view).
- **Import:** native open dialog → parse zip → optional **Replace existing keys** → `restore_keys`.
- DB index mismatch between archive and active database is rejected.
